# Fonts

IBM Plex Sans (Regular, Medium, SemiBold) and IBM Plex Mono (Regular, Medium), unmodified TTF files from IBM's releases `@ibm/plex-sans@1.1.0` and `@ibm/plex-mono@1.1.0` (https://github.com/IBM/plex). Licensed under the SIL Open Font License 1.1 (`OFL.txt`), with the Reserved Font Name "Plex". They are embedded in the desktop binary (`src/ui/fonts.rs`).
